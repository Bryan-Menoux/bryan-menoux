responsive, logique métier, services backend et automatisation du déploiement.

### Kiwanis Pays de Montbéliard

Plateforme associative full-stack conçue pour présenter le club, ses actions et
ses projets, tout en donnant aux membres des outils de gestion et un espace
utilisateur sécurisé.

- Interface responsive développée avec Astro, TypeScript et Tailwind CSS.
- Données, authentification et routes métier connectées à PocketBase.
- Formulaires, e-mails transactionnels et gestion explicite du consentement.
- Déploiement automatisé sur VPS avec GitHub Actions.

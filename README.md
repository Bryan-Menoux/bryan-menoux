## ◈ Profil

Je transforme des besoins concrets en expériences numériques **claires, utiles
et maintenables**. Mon approche full-stack couvre la conception d’interfaces
responsive, la logique métier, la gestion des données, l’intégration de services
et la mise en production.

```text
CONCEVOIR  →  DÉVELOPPER  →  FIABILISER  →  DÉPLOYER
```

### [Kiwanis Pays de Montbéliard][kiwanis-repo]

[![Déploiement Kiwanis](https://github.com/Bryan-Menoux/Kiwanis_Lorena_Chevallot_Leo_Baudry_Bryan_Menoux/actions/workflows/deploy.yml/badge.svg?branch=main)](https://github.com/Bryan-Menoux/Kiwanis_Lorena_Chevallot_Leo_Baudry_Bryan_Menoux/actions/workflows/deploy.yml)

Application web associative présentant le club, ses actions, ses projets, ses
produits et ses membres. Elle intègre un espace utilisateur, des interfaces de
gestion, des formulaires avec envoi d’e-mails et la gestion du consentement des
services externes.

| Dimension | Mise en œuvre |
| :-- | :-- |
| Interface | Astro, TypeScript, JavaScript, Tailwind CSS, DaisyUI |
| Services | Node.js, routes API, PocketBase, e-mails transactionnels |
| Qualité | Responsive design, images optimisées, gestion du consentement |
| Livraison | Déploiement automatisé sur VPS avec GitHub Actions |

[Voir le site en ligne](https://www.kiwanis-pays-de-montbeliard.fr) ·
[Explorer le code source][kiwanis-repo]
